# Portfolio Web

Site de portfolio personnel prêt à être personnalisé.

## Personnalisation

- Ouvre `index.html`
- Remplace `Ton Nom`, `Développeur / Designer / Freelance`, et le texte de chaque section par tes informations.
- Mets à jour l’email et le téléphone dans la section Contact.
- Ajoute tes vrais projets dans la section Projets.

## Structure

- `index.html` : page principale
- `styles.css` : styles visuels
- `script.js` : menu mobile

## Tester localement

Ouvre `index.html` directement dans ton navigateur ou utilise un serveur local simple.

## Astuce

Pour ajouter une vraie photo, place ton image dans `images/` puis remplace le bloc `.photo-placeholder` par une balise `<img src="images/ton-photo.jpg" alt="Photo de moi">`.
